# Lookup Anything

### See real-time information about anything in Stardew Valley

Lookup Anything adds an information overlay to Stardew Valley that shows you detailed stats, schedules, gift preferences, and crop info for anything you hover over — no more wiki-hunting mid-game.

<br>

---

## Features

| | |
|:---|:---|
| **Item Lookup** | See sell price, uses, and bundle info for any item in the game |
| **NPC Schedules** | View villager location schedules and gift preference lists instantly |
| **Crop Info** | Check days to harvest, season, and profit margin for any planted crop |
| **Contextual Data** | Information adapts based on what you're hovering — tools, crops, NPCs, more |
